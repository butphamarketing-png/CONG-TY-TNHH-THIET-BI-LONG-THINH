THIẾT KẾ WEBSITE CHUẨN CLOUDFLARE PAGES + SUPABASE + R2

Mục tiêu:

Xây dựng website NextJS chuyên nghiệp.

Kiến trúc bắt buộc:

Frontend:

* NextJS 15
* App Router
* TypeScript
* TailwindCSS

Hosting:

* Cloudflare Pages

Database:

* Supabase PostgreSQL

Storage:

* Cloudflare R2
